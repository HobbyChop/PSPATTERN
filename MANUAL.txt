PSPATTERN MANUAL


1. WHAT IT IS

PSPATTERN is a music tracker for the Sony PSP. You build a song from
patterns of notes, and the PSP generates the sound. It has a sampler, a
five engine synthesiser, a built in drum kit, a delay and a reverb, and
MIDI in and out through the PSP-MIDI adapter.

  Website and guide   https://pspattern.hobbychop.com
  Releases            https://github.com/HobbyChop/PSPATTERN/releases
  Source              https://github.com/HobbyChop/PSPATTERN
  Shop                https://hobbychop.com

It is a fork of LittleGPTracker by Marc Nostromo and is released under
the GNU General Public License version 3. The complete source is
included with this build.


2. INSTALLING

Copy the PSPATTERN folder to ms0:/PSP/GAME/ on your memory stick. The
folder must contain at least EBOOT.PBP. Launch it from the PSP game
menu.

The other files in the folder are:

  usbmidi.prx      the driver for the PSP-MIDI adapter
  config.xml       startup settings
  mapping.xml      button assignments
  custom_font.xml  the screen font
  samplelib        a folder for samples you want in reach of every song

usbmidi.prx is only needed if you have a PSP-MIDI adapter. Without it
the tracker runs normally and the MIDI instrument type does nothing.

Your PSP needs custom firmware to run homebrew. PSPATTERN has been
tested on 6.61 PRO-C.


3. BUTTONS

The manual refers to the PSP buttons by the names printed on them.

  O          Circle. Select, set, and the edit modifier.
  X          Cross. The secondary modifier.
  L and R    The shoulder triggers.
  START      Start and stop playback.
  SELECT     Marking on the grids, audition on the instrument screen.
  D-pad      Move the cursor.
  Nub        The analog stick. Browses and edits on the instrument
             screen.

Most editing is a modifier held with a direction. Holding O and pressing
left or right changes a value by one. Holding O and pressing up or down
changes it by sixteen, or by ten on the velocity column.

Hold R and the screen map appears; directions walk it, and releasing
R jumps. R is always the map and never anything else, which is why
muting and soloing are held with L instead. The bottom line of every
screen lists the moves available from where you are. It does not list
all of them. Copying, cloning, soloing and the rest are in section 8.


4. SCREENS

Hold R and a map of the screens appears with your current one
highlighted. Directions walk the highlight; release R to jump. The
map is laid out the way the screens relate:

  project  config  groove
  song     chain   phrase  instr
  fx       mixer   table   table

  SONG        the arrangement grid, one column per channel
  CHAIN       the list of phrases a song slot plays
  PHRASE      the notes themselves
  TABLE       a small automation sequence attached to a step
  GROOVE      per step timing
  INSTRUMENT  the sound design page
  MIXER       levels, filters, sends and the master EQ
  FX          the send effects and per channel inserts
  PROJECT     tempo, master level, file operations
  CONFIG      the settings from config.xml, editable in place

The table appears twice because it is reachable two ways: under
phrase it is the table the phrase is running, under instr it is the
table that instrument owns.

Jumps carry your place with them. Landing on the phrase screen from
the song screen opens the phrase reachable through the cell you were
standing on, however many levels the jump crossed, exactly as
stepping through the chain first would have.


5. THE SONG SCREEN

Eight columns, one per channel. Each cell holds a chain number in
hexadecimal, or two dashes for an empty slot.

Hold O and press up or down to place a chain. The tracker plays down the
rows. A channel with a blank cell at row zero never starts, so start
every channel you want to hear at row zero.

The info panel on the right carries the tempo, the project name, the
MIDI adapter, the battery, and the machine's health: dsp is the render
load (it turns into the worst recent figure with an exclamation mark
only when a block actually misses its deadline), me is how busy the
second processor is with the send effects, vfpu is the share of the
render spent in vector code, mem is the sample memory still free,
and und counts the times the audio queue ran dry since
play started -- zero is the only good number. The scope above it draws
the master output; under it, a spectrum of the mix, computed by the
second processor in its spare moments -- bass on the left, air on
the right. Both clear when the song stops.

L and X mutes the channel under the cursor.

IS THE ADAPTER WORKING

The mid row on that panel answers it, and there are three answers:

  PSPMIDI    an adapter is connected and ready
  no cable   the driver is loaded, nothing is answering it
  no drv     usbmidi.prx did not load at all

The two failures need different fixes, which is why they read
differently. "no cable" is what it says: check the lead, the adapter and
any hub. "no drv" means the driver never started, so no cable will help
-- usbmidi.prx is missing from beside the EBOOT, or another plugin has
taken the slot it needs. See the file list above for where the prx
belongs.

The row updates on its own while you work, so you can plug the adapter
in with the tracker running and watch it change.

BOOKMARKS

A song is 256 rows and the screen shows sixteen, so getting from the
intro to the last chorus is a lot of holding down. Mark the rows you
keep coming back to and jump between them.

  SELECT then O      mark the row under the cursor
  SELECT then X      clear it
  SELECT then v      go to the next marked row
  SELECT then ^      go to the previous one

A marked row is drawn in the value colour instead of the row colour.
Marks are saved with the song.

LIVE MODE

The song screen has two modes. In song mode it plays the arrangement
from the top. In live mode each channel is launched by hand and keeps
looping until you say otherwise, which is closer to a groovebox than
to a tape.

  X then < or >      switch between song and live mode

In live mode, O on a cell queues that chain rather than starting it,
so parts arrive on a musical boundary instead of wherever your thumb
landed. Press O on the same cell again and it comes in sooner: the
first press waits for the end of the chain, the second for the end of
the current phrase.

The live panel on the right has two rows. The mut row shows which
channels are muted. The cue row shows what each channel is waiting to
do, and counts the wait down:

  8 7 6 ...          steps left before this channel switches
  play colour        it is queued to start
  mute colour        it is queued to stop
  +                  further out than sixteen steps
  -                  nothing queued

The count is in steps, not in time. The groove decides how long each
step lasts, and a HOP in the phrase can end it early, so treat the
number as the number of steps still to play rather than a clock.


PROBABILITY

MAYB aa-b makes a step happen only sometimes. aa is the odds out of
FF: 00 never, FF always, 80 about half. A step with no MAYB on it
always happens, so nothing you wrote before this existed changes.

In a phrase it decides whether the note plays. A step it skips is left
alone rather than cut off, so whatever was already ringing keeps
ringing, exactly as an empty step would.

In a table it is a hop that only sometimes hops, and b is the row to
land on. The three command columns in a table each walk their own
position, so a MAYB in one column does not touch the others -- which
is what makes it useful: one column can wander while the others hold.

VIBRATO

VIBR aabb wobbles the pitch. aa is the speed, bb the depth in
sixteenths of a semitone, so 10 is one semitone, 02 is the smallest
wobble worth having and 80 is the widest. VIBR 0000 turns it off and
puts the pitch back where the note left it.

It is centred on the note, so a part with vibrato sits at the same
average pitch as one without. It also rides on top of whatever pitch
the step is already playing, so vibrato and an arpeggio can run at the
same time: the arpeggio moves the note, the vibrato bends around it.

On a MIDI instrument the wobble is sent as pitch bend, which means the
device's own bend range setting decides how far it actually goes.


6. THE CHAIN SCREEN

Sixteen rows. Each row holds a phrase number and a transpose value in
semitones. The chain plays its rows in order, then returns to the song.

Transpose shifts every note in that phrase. It is signed, so a value of
FE is two semitones down.


7. THE PHRASE SCREEN

Sixteen steps. Seven columns:

  note        the pitch, written as a note name and octave
  instrument  which instrument plays it
  velocity    how hard, 00 to 99, or two dashes for full
  command 1   an effect
  parameter 1 its value
  command 2   a second effect
  parameter 2 its value

The note column takes a note or two dashes for silence. Holding O and
pressing up or down moves by an octave, left or right by a semitone.

The velocity column reads 00 to 99 in decimal, not hexadecimal. Two
dashes means nothing is written and the step plays at full level, so a
phrase written before this column existed sounds the same as it always
did. Holding O and pressing up or down moves by ten, left or right by
one. One step below 00 clears it back to two dashes.

The command columns hold four letter effect names. Stand on one and the
panel at the bottom explains it. Hold O and press up or down to pick a
command from the list.


8. SELECTING, COPYING AND CLONING

The song, chain, phrase and table screens share one editing grammar.
None of it appears on the bottom line of the screen, so it is worth
reading once rather than hoping to find it.

ORDER MATTERS

The program looks at every button already held at the moment you press
the last one. A combination means hold the first and then press the
second. Pressing them the other way round runs whatever the first
button does on its own, which is usually not what you wanted.

MAKING A SELECTION

Hold X and press R. The cell under the cursor is highlighted. Move with
the D-pad and the selection grows to cover what you pass over.

  X then R          start a selection at the cursor
  X on its own      copy the selection and end it
  O then R          cut the selection
  O then direction  change every value in the selection at once
  R then X          widen: first to all columns, again to all sixteen rows
  L then X          interpolate the selection

With no selection up, hold O and press R to paste at the cursor. The
clipboard holds whatever you copied last, so a block can be pasted as
many times as you like.

CLONING

On the song and chain screens, hold R and press O to copy what is under
the cursor into a free slot and put the copy there. The original is
left alone, so a chain can be varied without disturbing every other
place it is used.

On the song screen a second O, with R still held, goes deeper: it
clones the phrases inside the chain as well, so nothing the copy
contains is shared with
what it came from.

INTERPOLATE

Interpolate draws a straight line between the first and last row of the
selection and fills in everything between.

The selection must be one column wide, and that column must be the note
column or one of the two parameter columns. There must be at least two
rows, and both ends must already hold a value. On notes, an empty cell
at either end gives the message No note info and nothing happens.

Put C-3 on row 0 and C-4 on row 8, select the note column between them
and interpolate, and the result is C-3, C#3, D#3, E-3, F#3, G-3, A-3,
A#3, C-4. Twelve semitones over eight steps does not divide evenly and
the remainder is dropped rather than rounded, which is why the steps
are uneven.

On a parameter column the four digits are treated as one number
counting up. That suits a volume or cutoff sweep. It does not suit a
command whose digits mean separate things, such as an arp shape.

CLONING

Hold R and press O. Whatever is under the cursor is duplicated to the
next free number and the cursor is repointed at the copy.

  Song screen        the chain under the cursor
  Chain screen       the phrase under the cursor
  Phrase screen      the instrument, or the table if the cursor is on
                     a TABL parameter
  Instrument screen  the instrument

Cloning is for when a part is used in several places and you want to
vary one of them. Editing the original would change all of them. If no
number is free it says so and changes nothing.

SINGLE STEPS

  O on its own  on an empty note step, repeat the last note and
                instrument entered
  X then O      clear the step, taking the instrument with the note and
                the parameter with the command
  X then L      mute the channel
  O then L      solo the channel

Pressing O on a step that already holds a note does not overwrite it.
It remembers that note and instrument as the pair to repeat next time,
which is how a sound is picked up from one row and stamped down the
phrase.

Mute and solo depend on which button you release first. Let go of L
while X is still down and the mute stays on. Let go of X while L is
still down and the channel comes straight back. The same combination
gives both a latch for arranging and a momentary drop for checking what
a part is doing.


9. COMMANDS

Each command takes a four digit parameter. The help panel writes the
parameter as aabb, meaning the first two digits and the last two are
read separately, or as aaaa when all four are one number.

  ARPG  cycle through pitches relative to the note
  CHRD  a chord: like ARPG but always at tick rate
  CRSH  drive and bit crush
  DLAY  delay the step by bb ticks
  DRIV  post filter drive, vax engine
  DTUN  detune spread of the unison stack, vax engine
  FBMX  feedback mix
  FBTN  feedback tune
  FCUT  set filter cutoff
  FLTR  set cutoff and resonance together
  FMFB  operator four self modulation, fm engine
  FML1  operator output level, fm engine
  FRES  set filter resonance
  GROV  switch to groove bb
  HOP   jump to step bb, aa times
  IRTG  retrigger the instrument and transpose
  KILL  stop the note after bb ticks
  LEGA  slide from the previous note
  LFOD  LFO depth
  LFOR  LFO rate
  LPOF  shift the sample loop points
  MAYB  a step that only sometimes happens
  MCCA  send a value on one of the instrument CC slots
  MDAT  MIDI channel pressure
  MDCC  send MIDI CC aa with value bb
  MDPB  MIDI pitch bend, 2000 is centre
  MDPG  MIDI program change
  MVEL  set MIDI velocity for the step
  PAN   pan to a value
  PFIN  pitch fine tune
  PLOF  jump within the sample
  PTCH  slide the pitch, aa is the rate and bb the amount
  RAND  scatter the note, aa semitones of pitch and bb of level
  RTGR  shape a retrigger, aa volume and bb pitch per repeat
  RTRG  retrigger every bb ticks
  STOP  stop the song
  TABL  start table bb
  TMPO  set the tempo
  TRSP  shift the note by bb semitones, and hold it there
  UNIS  unison voices, one to seven, vax engine
  VIBR  vibrato: speed aa, depth bb in sixteenths of a semitone
  VOLM  slide the volume

PTCH and VOLM take a rate in the first two digits. A rate of 00 jumps
straight to the target instead of sliding.


10. TABLES

A table is sixteen rows of three command columns and a transpose
column, running alongside a note. Use one for anything that has to
change over time, such as a filter sweep, an arpeggio, or a repeated
retrigger.

The transpose column is on the left, in semitones, and shifts the note
the table is running against. It is an offset rather than a new note,
so an arpeggio running underneath arpeggiates around the transposed
pitch instead of cancelling it. A row of -- is no transpose, so leaving
the column alone changes nothing.

Start a table from a phrase step with the TABL command, or set an
instrument to run one automatically from its table field.

Tables run at tick rate, which is faster than the phrase steps.


11. INSTRUMENTS

An instrument is one of three types. Change the type on the top row of
the instrument screen.

SAMPLE plays one of the built in drums, a wav file, or a preset from
a soundfont. Section 14 covers where those files go. It has volume,
pan, root note, fine tune, interpolation, loop mode and points, slice
count, a drive and bit crush stage, a filter with cutoff, resonance and
type, a feedback stage, an attenuator and an amplitude envelope.

MIDI sends notes out of the PSP-MIDI adapter. It has a channel, volume,
note length, pitch bend range and four CC slots.

SYNTH generates sound on the PSP. Pick one of five engines on the
second row.

THE INSTRUMENT DECK

The screen splits the controls by job. The d-pad owns identity: left
and right step the type, the engine, or the preset, and up and down
move between those three rows. It never wanders into the parameters.
The analog nub owns the parameters: alone it walks between them, and
with O held it turns the focused value -- slowly near the centre for
precision, faster as you push. The d-pad with O held edits too, one
step at a time, and if your nub is worn out, X with a direction does
what the nub does.

L with a direction is the only control that changes which instrument
slot you are editing.

SELECT plays the current instrument for as long as you hold it,
like a key: press for note on, release for note off. Tap it between
preset steps and you are browsing the bank by ear.


12. THE SYNTH ENGINES

TONE is a single oscillator. Saw, square, triangle or sine, with a pulse
width control on the square, a sub oscillator an octave down, and a
noise source. It is the cheapest engine.

PDX is phase distortion. Saw, square, resonant saw and resonant triangle.
The mod envelope sweeps the distortion amount, which is what gives it
the resonant sweep without a filter.

VAX is the analogue style engine. A stack of up to seven detuned
oscillators, saw or pulse, with pulse width modulation, a sub oscillator,
noise, hard sync and ring modulation.

FM is four operator frequency modulation with eight algorithms. The
algorithm names describe the routing directly. A greater than sign means
the operator on the left modulates the one on the right, a space
separates independent branches, and any operator not followed by a
greater than sign reaches the output. Each operator has a ratio, level,
detune and its own envelope.

VOX is a formant engine, a voice rather than an instrument. The
cutoff control morphs the sound between two vowels of your choosing,
picked on the vowel a and vowel b rows, and the source wave, pulse
width and a noise source colour the throat behind them. Point the
LFO at flt and the vowels move on their own, which is where the
talking comes from.

PRESETS

The third row of the synth page is the preset. Left and right step
through the bank and stepping loads: land on a name and that sound
is in the slot, engine and all. Browsing is silent -- press SELECT
to hear the one you are on. The "--" entry is where you started:
the sound is snapshotted the moment browsing leaves it, and
stepping back restores it, so the bank can always be backed out
of. O with up or down jumps sixteen at a time.

Tap O on the preset row to save what you have under a name of your
own; X backs out of the name dialog. Presets live in the presets
folder next to the EBOOT as plain name=value text files, one per
sound -- readable, editable and small enough to share. More than a
hundred come with this build, and yours land beside them. A preset
stores the sound alone; it never carries a table with it.

FM is selectable by default; setting fm to NO on the config screen
hides it from the engine picker, as a guard rail for the CPU cost.
Loading an FM preset works either way.


13. HARD SYNC AND RING MODULATION

Both are on the VAX engine and both are off at zero, so patches made
before they existed are unaffected.

SYNC runs a silent master oscillator at the note frequency. The
oscillators you hear are lifted to between one and four times that
frequency, and every time the master completes a cycle they are reset to
the start. The pitch you hear stays on the note while the timbre climbs.
Sweeping sync from a table is the classic hard sync lead.

RING multiplies the oscillator by a sine running one octave below the
note. At zero the oscillator passes through untouched. At full you hear
only the product. It adds tones halfway between the normal harmonics,
which is what makes it sound metallic or hollow. It is applied before
the sub oscillator and the noise, so a ring modulated lead keeps a solid
bottom end.

Sync and ring together produce the most aggressive sounds the engine
makes.

Both are patch parameters. They cannot yet be changed from a phrase or
table command.


14. SAMPLES AND SOUNDFONTS

A sample instrument plays one of the built in drums, a wav file, or a
preset from a soundfont. Each project carries its own set.

WHERE FILES GO

Every project is a folder named lgpt_NAME under
ms0:/PSP/GAME/PSPATTERN/, and inside it is a samples folder:

  ms0:/PSP/GAME/PSPATTERN/lgpt_MYSONG/samples/

Everything in there is read when the project opens. Copying a wav into
that folder from a computer is all that is needed. There is no import
step and nothing else to update.

Creating a project on the PSP makes the project folder and its samples
folder for you.

THE SAMPLE LIBRARY

Beside the projects is a folder called samplelib:

  ms0:/PSP/GAME/PSPATTERN/samplelib/

Nothing in it is loaded or playable on its own. It is the folder the
import browser opens in, so it is where to keep files you want within
reach of every song. You can fill it before you have created a single
project, and it may hold subfolders.

If samplelib is missing, importing reports that it cannot access the
library. Creating an empty folder with that name is the fix.

IMPORTING

On the instrument screen set the type to SAMPLE, move to the file field
and press O. The browser opens in samplelib. Choosing a file copies it
into the current project samples folder and loads it straight away.

It is a copy. The original stays in samplelib and the project gets its
own version. That is what makes a project folder complete on its own:
move it to another memory stick and it still plays. It also means a
file used in four projects is stored four times.

Saving a song does not move or copy any audio. The copy already
happened when you imported.

THE SAMPLE LIST

The list is sorted alphabetically, and the drums, your wav files and
any soundfont presets sit in it together. A file named Bassline lands
between ANTOMLO and HDCLAP rather than at the end. Sorting is by
character code, so capitals come before lower case.

A project stores the name of the sample an instrument uses, not its
position in the list. Adding or removing other files does not repoint
an instrument at the wrong sample. A name that cannot be found gives no
sample and silence rather than something else.

SOUNDFONTS

A .sf2 file in a project samples folder is read when the project opens,
and every preset in it appears in the sample list under its own name.
Note ranges, root keys and loop points come from the file, so a preset
with several samples mapped across the keyboard plays the right one for
each note.

Limits:

  Three .sf2 files per project. A fourth is not loaded.

  Presets share the 128 slot sample list with the drums and your wavs.

  Presets play in mono. A stereo preset uses its left sample.

  Velocity layers are not chosen. The loudest layer plays at every
  velocity. The velocity column still sets the volume.

  The whole bank is held in memory while the project is open. A large
  soundfont may not fit, and anything that does not fit is silent.

The start, loop and end fields on the instrument screen read zero for a
preset. Those values are per note for a soundfont and the screen has
one set of fields to show them in.


15. THE DRUM KIT

The drum instruments are generated when a project loads, not read from
sample files. That is what the progress line on the loading screen is
doing. They cost no disk space and can be redistributed freely.

Each drum has a soft and a hard variant.


16. THE MIXER AND THE SEND EFFECTS

Each channel has a level, a high pass, a low pass, and a send to the
delay and to the reverb. The two send effects are shared by all
channels.

Up and down move through the rows of a strip. The four settings of the
send effects themselves sit on one line below the strips, and left and
right walk between them. Up from that line returns to the strips.

The master has a drive control, a clipper with several modes, and a
gain switch.

THE MASTER EQ

Under the send effects is a line of ten bands, octave spaced from about
40Hz to the top. It shapes the whole mix, not one channel, which is why
it sits with the sends rather than on a strip.

  left, right      move between bands
  O and up/down    move a band in eights
  O and left/right move a band by one
  X and O          set the band under the cursor back to flat

Flat is the middle and is where every band starts. While every band is
flat the EQ is skipped entirely and costs nothing at all, so leaving it
alone is free.

It is a tone shaper rather than a surgical EQ: the bands overlap, so
lifting one moves its neighbours a little too. Moving one band costs
two filters, and a shape that changes only in a couple of places costs
the same -- what it charges for is the number of places the curve
changes, not the number of bands you have touched.

WHAT EACH STRIP IS CARRYING

Beside each channel number is one letter saying what kind of instrument
that strip last played:

  y    a synth
  s    a sampler
  m    MIDI
  -    nothing has played on this channel yet

It follows the last instrument rather than the sounding one, so it does
not blink off in the gaps between notes.

READING THE METERS

There are nine bars. The eight on the left are the channels; the one on
the right is the master.

The master bar is the only one showing a SUM, so it routinely reads
higher than any single channel, and that is not a fault. Eight channels
at a third of full scale each add up to more than twice full scale.
Every mixer behaves this way; it is why parts have to come down as the
track count goes up.

The channel bars are taken after that channel's own gain, so the mixer
controls move them. The master fader deliberately does not move them --
a channel bar answers "what is this strip sending", not "what is left
of it after the master".

The figure on the title strip reads

  sat NN%

which is how much of the last moment the master sum spent pinned at the
top. Zero means the mix fits. Anything climbing means the channels are
adding up to more than the mixer can hold, and the sound is being
squared off before the fader or the clipper ever see it. That is the
state where a mix sounds crushed while every channel strip still looks
perfectly reasonable, so it is worth a glance when something sounds
wrong and you cannot see why.

Bring it back to zero by turning channels down, or the master, or both.

THE FX SCREEN

The send effects have a screen of their own. The reverb rows set
size and damping; freeze holds the tail the reverb has and
recirculates it; duck lets what you send push the tail down out of
the way, and gate only lets the tail through while the send is
above the threshold -- the gated-reverb drum trick. locut is a low
cut on what enters the tail, which is the cure for a frozen hold
turning to mud, and width spreads the tail wider than the room.

The delay rows set time and feedback; tone is a filter inside the
feedback loop, so every repeat comes back darker, the way a tape
echo dies. At zero the delay is exactly what it always was.

drive pushes the combined wet signal into a soft clipper, and comp
is a one-knob compressor on the wet bus that runs before the drive,
so the drive saturates an evened signal instead of doing the
evening. Below them, pick a channel and give it its own phaser or
chorus -- a rate and a depth each, per channel, on top of whatever
the sends are doing.


17. THE PROJECT SCREEN

  tempo    beats per minute, and the tick count in brackets
  transp   transpose the whole song
  scale    constrain notes to a scale
  master   master output level
  repeat   whether the song loops
  drive    input drive to the master stage
  clip     the clipper mode
  gain     unity or boost
  device   MIDI output device
  rate     audio sample rate
  sync     follow an external MIDI clock

The file column has load, save, save as, two compaction tools, and a
render switch.

MIDI CLOCK

The tracker sends MIDI clock whenever it plays, twenty four pulses to
the quarter note as the standard asks, with a start when the transport
starts and a stop when it stops. Gear plugged into the adapter follows
the tracker with nothing to switch on. To silence it, add

  <MIDISENDSYNC value="NO"/>

to config.xml beside the EBOOT.

The sync setting above is the other direction: on Follow the tracker
takes its tempo from an incoming clock instead of running its own.
Following is opt in, because a stray clock byte from a device you left
plugged in should not take the transport away from you.

On Follow the leader owns the transport, so START does not start the
song. It arms it: the bottom row reads

  waiting for midi start

and the song begins when the leader does. Press START again while it
waits to give up. Stopping is still immediate and still yours -- a song
you want stopped stops when you say so, leader or not.

This is what a piece of MIDI gear in external sync does, and it is the
only way to come in with the leader rather than free running beside
it.

While following, the bpm figure on the song screen is coloured: the
play colour once the tracker has locked to the leader, the mute colour
while it is still catching up. It should lock within a bar or two if
the song's own tempo is near the leader's, and inside about seven bars
if it is a long way off. If it stays in the mute colour the leader's
clock is not arriving cleanly.

The tempo shown is the leader's, not the one saved with the song.

SYNC OFFSET

Locking the two clocks together is not the same as the two being
heard together. What gets aligned is the moment the tracker decides a
tick; what you hear is that tick coming out of the audio buffer some
time later. The tracker measures its own share -- the audio pipe, the
slice in flight -- and runs early by exactly that, at any tempo and
any buffer setting.

What it cannot know is the rest of the chain: how long a clock byte
takes to reach it, and what your own gear's output latency is. Trim
that once with synco on the config screen (also MIDISYNCOFFSET in
config.xml): milliseconds, signed, positive plays earlier, applied at
the next play start. Around 50 suits a typical computer DAW over a
USB interface; a hardware sequencer wants nearer zero. Because the
measured share tracks your settings, the number you dial describes
only your gear -- it survives tempo and buffer changes.


THE CONFIG SCREEN

The settings from config.xml, editable on the machine. Theme changes
apply as you step through them, so you pick by looking. Rows marked
with a star are read once at boot -- the screen saves them and tells
you a reboot is needed. Everything saves by itself when you leave
the screen.


AUTOSAVE

The machine writes a crash-recovery file on its own -- but only when
the transport is stopped, nothing has changed for a while, no button
has been touched for longer, and the OUTPUT has been silent for a few
seconds, so a reverb tail ringing past the end of a song is never
chewed by the Memory Stick write. Playing live, set asave to NO on
the config screen (or AUTOSAVE NO in config.xml) and the machine will
never touch the stick on its own at all. It applies immediately, and
manual saving is not affected.


18. SAVING AND RENDERING

Save song writes to the current project folder. Save song as makes a new
one. Projects live in ms0:/PSP/GAME/PSPATTERN/lgpt_NAME/.

The tracker also keeps an automatic backup. If it was interrupted, it
offers to recover the unsaved changes the next time you open the
project.

Set render to Stereo and press START to write mixdown.wav into the
project folder while the song plays. Set it back to Off when you are
done, or every play writes a new file.


19. LEVELS

Instrument volume runs from 0 to 255 and is shown as a percentage of
that range. Note that 50 percent is unity gain, not half volume. Above
50 percent the instrument is amplified, up to about six decibels at 100
percent. If a mix sounds quiet, this is the first thing to check.

The two demo songs shipped with this build peak around ten decibels
below full scale and are known to be too quiet.


20. KNOWN ISSUES

  The PAN command on sample instruments is unverified and may not work.

  Sync and ring cannot be sequenced from a command, only set on the
  patch.

  The synth envelope values are shown in hexadecimal while the sliders
  on the same page are shown as percentages.

  A few stray pixels are drawn on the bottom rule of the oscillator
  panel underneath the ring slider. It is cosmetic.
